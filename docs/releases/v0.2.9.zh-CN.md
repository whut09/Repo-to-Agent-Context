# OpenCode++ v0.2.9

本版本修复了一个会让 OpenCode Desktop 看起来“卡死”的 Harness 循环。

## 修复内容

- `opencode-plusplus tests` 现在被正确识别为测试选择器，而不是真实测试执行结果。
- 测试选择器输出不能再满足 command test evidence。
- 仓库没有可执行测试命令时，会明确停止在 `human-review`，不再重复 `tests -> evaluate`。
- Desktop 返回的 required commands 不再包含测试选择器或说明文本。
- `evaluate` 会在增量验证器中复用已加载的仓库 Context，避免重复构建 Context。

## 安装

关闭 OpenCode Desktop，运行 `opencode-plusplus-setup-win-x64.exe`，重启 OpenCode Desktop，然后选择 **OpenCode++**。当仓库没有配置测试命令时，OpenCode++ 现在会显示 `human-review`，而不是反复调用测试选择器。
