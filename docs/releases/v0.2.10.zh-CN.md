# OpenCode++ v0.2.10

本版本修复 Desktop Harness 等待循环，以及运行时文件变化导致的重复验证。

## 修复内容

- Desktop 使用进程内 OpenCode++ 工具，并禁止 CLI、`Start-Sleep`、`sleep` 和轮询循环。
- Sidecar 会拦截人为等待命令，并返回明确的下一步。
- 插件 Context 按当前 working tree 指纹缓存，并合并并发构建。
- `.agent-context` 和生成的 `AGENTS.md` watcher 事件不再把仓库标记为 dirty，也不再触发重复验证。
- 仓库没有真实测试命令时，Desktop 仍会结构化返回 `human-review`。

## 安装

关闭 OpenCode Desktop，运行 `opencode-plusplus-setup-win-x64.exe`，重启 OpenCode Desktop，然后选择 **OpenCode++**。
