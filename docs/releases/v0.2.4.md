# OpenCode++ v0.2.4

This release changes the Windows Desktop integration to a native OpenCode primary mode.

## Install And Use

1. Download `opencode-plusplus-setup-win-x64.exe` and its SHA256 file.
2. Fully exit OpenCode Desktop and double-click the EXE.
3. Restart OpenCode Desktop.
4. Select **OpenCode++** in the mode picker and describe the task normally.

## Highlights

- Installs `agents/opencode-plusplus.md` with `mode: primary`.
- Removes the old OpenCode++ Slash Commands and skill files.
- Stops patching `app.asar`; upgrades can restore the old patch when its original backup is available.
- Keeps Harness retrieval, evidence, guard, policy, convergence, and report behavior inside the plugin.
- Documents the problem, current capability, extension points, boundaries, and contribution workflow.

## Compatibility

The product targets Windows x64 and the official OpenCode Desktop configuration layout. CLI and MCP remain developer/compatibility surfaces. Existing repositories can customize the agent or fork the plugin when their Harness policy needs differ.
