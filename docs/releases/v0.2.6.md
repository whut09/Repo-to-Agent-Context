# OpenCode++ v0.2.6

This release makes the Desktop Harness visible during normal OpenCode work.

## What Is New

- Added the `opencode_plusplus_dashboard` Desktop tool.
- Harness tool results now include a structured `visualization` snapshot.
- The dashboard shows phase progress, selected and rejected files, findings, missing evidence, required commands, evidence freshness, intervention counts, the current decision, and the next action.
- The latest snapshot is written to `.agent-context/sidecar/visualization.json`; the existing Markdown report remains available at `.agent-context/sidecar/latest.md`.
- Added explicit wording that the dashboard contains recorded system facts and deterministic decision inputs, not hidden model chain-of-thought.
- Kept existing plugin tools and public behavior compatible.

## Install

1. Close OpenCode Desktop completely.
2. Download `opencode-plusplus-setup-win-x64.exe` and its SHA256 file.
3. Double-click the installer.
4. Restart OpenCode Desktop and select **OpenCode++** in the mode picker.

After `evaluate` or `next`, inspect the returned **OpenCode++ Harness Dashboard**. It explains what OpenCode++ selected, rejected, prevented, requested, verified, or left for human review.

The dashboard does not expose private model reasoning. Commands, file selections, findings, evidence hashes, and decisions are the auditable records. OpenCode++ still uses the current OpenCode model and does not call a second model.
