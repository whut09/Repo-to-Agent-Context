# OpenCode++ v0.2.4

本版本把 Windows Desktop 集成改为 OpenCode 原生 primary mode。

## 安装和使用

1. 下载 `opencode-plusplus-setup-win-x64.exe` 和 SHA256 文件。
2. 完全退出 OpenCode Desktop，双击 EXE。
3. 重启 OpenCode Desktop。
4. 在模式选择器中选择 **OpenCode++**，像平常一样描述任务。

## 重点更新

- 安装 `mode: primary` 的 `agents/opencode-plusplus.md`。
- 删除旧版 OpenCode++ Slash Command 和 skill 文件。
- 停止修改 `app.asar`；如果存在原始备份，升级时可以恢复旧补丁。
- 保留插件内的 Harness retrieval、evidence、guard、policy、convergence 和报告能力。
- 补充问题定义、当前能力、扩展点、边界和贡献流程文档。

## 兼容性

产品面向 Windows x64 和官方 OpenCode Desktop 配置布局。CLI 和 MCP 仍是开发者/兼容面。如果仓库需要不同 Harness policy，可以定制 agent 或 fork 插件。
