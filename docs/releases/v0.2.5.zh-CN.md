# OpenCode++ v0.2.5

本版本补全文档并明确 Context Hub 风格 Desktop Harness 的边界。

## 重点更新

- 以英文首页为默认入口，补充 Context Registry、Retrieval、Guard、Evidence 和 Intervention 的关系。
- 明确区分选中/排除文件、阻止风险、建议修复、已验证修复和仍需人工处理。
- 说明 Context cache、usage、feedback、annotation、trace、intervention 和 sidecar 的运行时位置。
- 明确外部 Context 是不可信指导，annotation 不是 policy，插件也不是操作系统级沙箱。
- 补充 Windows 路径、权限、离线、网络失败和发布包边界。
- Desktop 插件默认离线运行，不调用第二个模型。

## 安装和使用

1. 下载 `opencode-plusplus-setup-win-x64.exe` 和 SHA256 文件。
2. 完全退出 OpenCode Desktop，双击 EXE。
3. 重启 OpenCode Desktop。
4. 在模式选择器中选择 **OpenCode++**，像平常一样描述任务。

## 兼容性

产品面向 Windows x64 和官方 OpenCode Desktop 配置布局。CLI 和 MCP 仍是开发者与兼容性入口。根目录 `package.json` 是唯一版本来源。运行时 artifact、benchmark 输出、安装器 staging 和本地配置不属于 npm 包或 Git 源码发布物。
