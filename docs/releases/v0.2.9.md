# OpenCode++ v0.2.9

This release fixes a Desktop Harness loop that could look like OpenCode was frozen.

## Fixed

- `opencode-plusplus tests` is now correctly treated as a test selector, not a test execution result.
- Test selection output can no longer satisfy command test evidence.
- Repositories without a runnable test command now stop at `human-review` with a clear diagnostic instead of repeating `tests -> evaluate`.
- Desktop required commands no longer include the test selector or explanatory text.
- `evaluate` reuses its loaded repository context in the incremental verifier, avoiding a duplicate context build.

## Install

Close OpenCode Desktop, run `opencode-plusplus-setup-win-x64.exe`, restart OpenCode Desktop, and select **OpenCode++**. When a repository has no configured test command, OpenCode++ now reports `human-review` instead of repeatedly invoking the selector.
