# OpenCode++ v0.2.11

本版本让 Desktop 结果明确显示 OpenCode++ 自己做了什么。

## 变更内容

- 每个 Harness 结果新增 `actionSummary`，记录 `observed`（检测到）、`prevented`（已阻止）、`requested`（已要求）、`repaired`（已修正）、`verified`（已验证）和 `unresolved`（未解决）。
- `humanReadable` 首部显示同一份中英文行动总结、当前工作树 hash 和证据缺口。
- Desktop app log 增加阻止、修正、验证和未解决介入的计数。
- primary mode 现在要求当前模型直接引用插件记录的总结，不能用提交列表或外部测试声明替代。
- `human-review` 表示插件报告了具体缺失证据或边界决策，不是要求用户重新做一遍任务。

这份总结是插件记录事实的审计结果，不展示模型隐藏思维，也不会把模型或用户声明当作 OpenCode++ 证据。

## 安装

关闭 OpenCode Desktop，运行 `opencode-plusplus-setup-win-x64.exe`，重启 OpenCode Desktop，然后选择 **OpenCode++**。调用 `evaluate` 或 `next` 后，查看结果顶部的 `OpenCode++ action summary`，也可以调用 `opencode_plusplus_dashboard`。
