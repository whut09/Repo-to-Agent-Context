# OpenCode++ v0.2.8

本版本让 Desktop Harness 状态保持可见，同时避免重复显示完全相同的通知。

## 新增内容

- `evaluate`、`next` 和 `dashboard` 会在 Desktop 显示简短的 OpenCode++ Harness 状态 toast。
- 完全相同的结果只通知一次；decision 或 evidence 状态变化后会再次显示。
- 所有 Harness 工具调用都会向 OpenCode app log 写入结构化状态行。
- 完整结构化可视化仍会包含在 tool result 中，并写入 `.agent-context/sidecar/visualization.json`。
- 状态只包含已记录的事实和确定性决策输入，不展示模型隐藏的思维链。

## 安装

关闭 OpenCode Desktop，运行 `opencode-plusplus-setup-win-x64.exe`，然后重启 OpenCode Desktop 并选择 **OpenCode++**。调用 `evaluate` 或 `next` 后，toast 和 app log 会直接显示 OpenCode++ 状态。
