# OpenCode++ v0.2.1

本次补丁修复 OpenCode Desktop 插件发现问题，并纠正状态与开关入口的产品边界。

## 主要修复

- 修复 OpenCode 1.18.18 加载全局插件时的 CommonJS 导出兼容问题。
- 删除旧控制类 Slash Command；OpenCode Markdown Command 本质是发送给模型的 Prompt Template。
- 保留 `opencode_plusplus_status`、`opencode_plusplus_enable` 和 `opencode_plusplus_disable`，它们是模型可见的 Desktop 工具。
- Windows 安装器提供 `--status`、`--enable` 和 `--disable`，用于无需模型的本地直接控制。
- 升级时保留 enabled 状态，并同步更新插件版本信息。
- 用轻量 .NET Framework 安装器替换 Node SEA，EXE 从 96.6 MiB 降至约 3.5 MiB。

## 安装方式

1. 完全退出 OpenCode Desktop。
2. 下载 `opencode-plusplus-setup-win-x64.exe`。
3. 使用同页 SHA256 文件校验下载内容。
4. 运行安装器，然后重新启动 OpenCode Desktop。

安装器仅作用于当前用户，不需要管理员权限。当前二进制未做商业代码签名。

## 验证结果

- TypeScript 检查、Lint、格式检查、CLI 文档检查和中英文文档检查均通过。

- Windows 安装、禁用、启用、插件加载和卸载冒烟测试通过。
