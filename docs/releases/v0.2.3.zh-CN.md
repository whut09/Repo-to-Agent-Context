# OpenCode++ v0.2.3

本版本完成面向 Windows 官方 OpenCode Desktop 的 Desktop-only 产品收尾。

## 安装与使用

1. 从本 Release 下载 `opencode-plusplus-setup-win-x64.exe` 和 SHA256 文件。
2. 完全退出 OpenCode Desktop。
3. 双击 EXE。
4. 重启 OpenCode Desktop 并打开目标仓库。
5. 在新会话运行 `/plusplus-task <任务>` 或 `/plusplus-verify`。
6. 使用 `/opencode-plusplus-status`、`/opencode-plusplus-on` 和 `/opencode-plusplus-off` 在本地查看或切换状态，不调用模型。

## 重点更新

- `prepare`、`retrieve`、`evaluate`、`next` 作为 Desktop 进程内插件工具运行，不启动 OpenCode++ CLI。
- 增加自适应 retrieval、符号/依赖/regression 权重、增量 context 复用和结构化超时遥测。
- 统一 evidence freshness 与 supersede 规则：相同等价命令采用最新结果，同时不隐藏无关命令失败。
- 在 Loop、Policy、Guard Gate 和 Orchestrator 中统一 advisory、balanced、strict 三种 evidence policy。
- 增加确定性决策仲裁、重复状态/no-progress 收敛、可恢复 Orchestrator Phase 和多轮增量 context 刷新。
- Windows 下 Desktop state、session、workflow、trace、event 和 report 统一原子写入并支持 revision 冲突诊断。
- Desktop hook 事件通过 `eventId` 幂等去重，并在跨进程文件锁内分配单调递增 `sequence`。
- 普通 artifact 故障不会导致 OpenCode Desktop 崩溃，明确的命令/路径 Guard blocker 仍保持阻塞。

## 发布安全

- 安装器保持轻量，不携带 Node.js、第二套 UI runtime 或 OpenCode 本体。
- Windows 发布 gate 验证 EXE 体积、SHA256、manifest version、独立插件加载、三条本地命令、app.asar patch marker、original backup、中断写恢复和 uninstall restore。
- 确定性 Desktop Harness benchmark 的付费模型调用数为 0。
- 手动 Desktop release CI 会安装官方 `SST.OpenCodeDesktop` winget 包，并在发布资产前验证真实应用可以启动。
- npm 开发包不包含 runtime `.agent-context`、benchmark fixture、agent-runs、release staging、测试、源码和开发脚本。

## 兼容边界

插件面向 Windows x64 和当前官方 OpenCode Desktop bundle 结构。目标 bundle 缺少所需 `SessionPrompt.command` marker 时，安装器会失败且不写 command 文件。安装或升级前必须完全退出 OpenCode；OpenCode Desktop 更新替换 `app.asar` 后需要重新运行安装器。

CLI 与 MCP 只保留为开发者/兼容面。Desktop 用户仅通过 EXE 和 OpenCode Desktop 界面安装、使用本版本。
