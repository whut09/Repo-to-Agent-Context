# OpenCode++ v0.2.3

This release completes the Desktop-only product path for the official OpenCode Desktop application on Windows.

## Install And Use

1. Download `opencode-plusplus-setup-win-x64.exe` and its SHA256 file from this release.
2. Fully exit OpenCode Desktop.
3. Double-click the EXE.
4. Restart OpenCode Desktop and open a repository.
5. Run `/plusplus-task <task>` or `/plusplus-verify` in a new session.
6. Use `/opencode-plusplus-status`, `/opencode-plusplus-on`, and `/opencode-plusplus-off` for local model-free status controls.

## Highlights

- Runs `prepare`, `retrieve`, `evaluate`, and `next` as in-process Desktop plugin tools without spawning the OpenCode++ CLI.
- Adds adaptive retrieval, symbol/dependency/regression weighting, incremental context reuse, and structured timeout telemetry.
- Unifies evidence freshness and supersede rules so the newest equivalent command result wins without hiding unrelated failures.
- Adds configurable advisory, balanced, and strict evidence policies across Loop, Policy, Guard Gates, and Orchestrator.
- Adds deterministic decision arbitration, repeated-state/no-progress convergence, resumable orchestrator phases, and incremental multi-loop context refresh.
- Makes Desktop state, session, workflow, trace, event, and report persistence atomic and revision-aware on Windows.
- Deduplicates repeated Desktop hook events with `eventId` and assigns monotonic `sequence` values under a cross-process lock.
- Keeps ordinary artifact failures from crashing OpenCode Desktop while preserving explicit command/path Guard blockers.

## Release Safety

- The installer remains compact and does not bundle Node.js, a second UI runtime, or OpenCode itself.
- The Windows release gate verifies EXE size, SHA256, manifest version, standalone plugin loading, three local commands, the app.asar patch marker, original backup, interrupted-write recovery, and uninstall restoration.
- A deterministic Desktop Harness benchmark runs with zero paid model calls.
- Manual Desktop release CI installs the official `SST.OpenCodeDesktop` winget package and verifies that the real application launches before assets are published.
- Runtime `.agent-context` artifacts, benchmark fixtures, agent runs, release staging, tests, source files, and developer scripts are excluded from the npm developer package.

## Compatibility

The plugin targets Windows x64 and the current official OpenCode Desktop bundle shape. Installation fails without changing command files when the required `SessionPrompt.command` marker is unavailable. Fully close OpenCode before installation or upgrade, and rerun the installer after an OpenCode Desktop update replaces `app.asar`.

CLI and MCP remain developer/compatibility surfaces only. Desktop users install and use this release entirely through the EXE and OpenCode Desktop UI.
