# OpenCode++ v0.2.2

This patch restores visible OpenCode++ commands in OpenCode Desktop without sending them to the selected model.

## Changes

- Adds `/opencode-plusplus-status`, `/opencode-plusplus-on`, and `/opencode-plusplus-off` to the Desktop command menu.
- Applies a marker-checked patch to `SessionPrompt.command`, intercepting only those exact names before normal prompt-template handling.
- Writes status and enable/disable results directly into the current session with zero model or shell execution.
- Backs up the original `app.asar` and restores it on uninstall.
- Reapplies the patch after OpenCode updates replace the bundle.
- Rebuilds the archive in place, adding only about 3 KiB instead of duplicating the large host chunk.

## Supported Host

The release is verified against OpenCode Desktop 1.18.18 on Windows x64. Installation fails without modifying command files when the required bundle marker is unavailable. Fully close OpenCode before installing or uninstalling, and rerun the installer after an OpenCode update.
