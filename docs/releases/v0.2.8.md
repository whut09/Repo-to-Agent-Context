# OpenCode++ v0.2.8

This release keeps the Desktop Harness status visible without repeating identical notifications.

## What Is New

- `evaluate`, `next`, and `dashboard` show a compact OpenCode++ Harness status toast in Desktop.
- Repeated identical results are deduplicated; a new decision or changed evidence state is shown again.
- All Harness tool calls write a structured status line to the OpenCode app log.
- Full structured visualization remains in the tool result and `.agent-context/sidecar/visualization.json`.
- The status contains recorded facts and deterministic decision inputs; it does not expose hidden model chain-of-thought.

## Install

Close OpenCode Desktop, run `opencode-plusplus-setup-win-x64.exe`, then restart OpenCode Desktop and select **OpenCode++**. After `evaluate` or `next`, the toast and app log show the OpenCode++ status directly.
