# OpenCode++ v0.2.2

本补丁恢复 OpenCode Desktop 中可见的 OpenCode++ 命令，并确保执行时不把命令发送给当前模型。

## 变更

- 在 Desktop 命令菜单增加 `/opencode-plusplus-status`、`/opencode-plusplus-on` 和 `/opencode-plusplus-off`。
- 对 `SessionPrompt.command` 应用经过特征检查的补丁，只在正常 Prompt Template 处理前拦截这三个精确名称。
- 状态、启用和禁用结果直接写入当前会话，不执行模型或 Shell。
- 备份原始 `app.asar`，卸载时恢复。
- OpenCode 更新替换 bundle 后，可以重新运行安装器重新应用补丁。
- 在原位置重建归档，只增加约 3 KiB，不再重复打包大型宿主 chunk。

## 支持范围

本版本已在 Windows x64 的 OpenCode Desktop 1.18.18 上验证。若目标 bundle 不存在所需特征，安装器会失败且不写命令文件。安装或卸载前必须完全退出 OpenCode；OpenCode 更新后需要重新运行安装器。
