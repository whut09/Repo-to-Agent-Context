# OpenCode++ v0.2.6

本版本让 Desktop Harness 在 OpenCode 正常工作过程中变得可见。

## 新增内容

- 新增 `opencode_plusplus_dashboard` Desktop 工具。
- Harness 工具结果现在包含结构化 `visualization` 快照。
- Dashboard 展示阶段进度、选中和排除的文件、findings、缺失 evidence、必跑命令、证据新鲜度、介入统计、当前 decision 和下一步动作。
- 最新快照写入 `.agent-context/sidecar/visualization.json`；原有 Markdown 报告仍在 `.agent-context/sidecar/latest.md`。
- 明确说明 Dashboard 展示已记录的系统事实和确定性决策输入，不展示模型隐藏的思维链。
- 保持现有插件工具和公开行为兼容。

## 安装

1. 完全关闭 OpenCode Desktop。
2. 下载 `opencode-plusplus-setup-win-x64.exe` 和 SHA256 文件。
3. 双击安装器。
4. 重启 OpenCode Desktop，在模式选择器中选择 **OpenCode++**。

在 `evaluate` 或 `next` 后查看返回的 **OpenCode++ Harness Dashboard**。它会说明 OpenCode++ 选中了什么、排除了什么、阻止了什么、要求了什么、验证了什么，以及哪些问题仍需人工处理。

Dashboard 不展示模型私有推理。命令、文件选择、finding、证据 hash 和 decision 才是可审计记录。OpenCode++ 仍使用当前 OpenCode 模型，不调用第二个模型。
