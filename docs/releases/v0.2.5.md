# OpenCode++ v0.2.5

This release documents and hardens the Context Hub-style Desktop Harness boundary.

## Highlights

- Explains the Context Registry, Retrieval, Guard, Evidence, and Intervention flow in the English-first documentation.
- Distinguishes selected and rejected files, prevented risks, suggested repairs, verified fixes, and remaining human review.
- Documents Context cache, usage, feedback, annotations, traces, interventions, and sidecar runtime locations.
- Clarifies that external Context is untrusted guidance, annotations are not policy, and the plugin is not an operating-system sandbox.
- Documents Windows path, permission, offline, network failure, and release package boundaries.
- Keeps the Desktop plugin offline by default and avoids a second model call.

## Install And Use

1. Download `opencode-plusplus-setup-win-x64.exe` and its SHA256 file.
2. Fully exit OpenCode Desktop and double-click the EXE.
3. Restart OpenCode Desktop.
4. Select **OpenCode++** in the mode picker and describe the task normally.

## Compatibility

The product targets Windows x64 and the official OpenCode Desktop configuration layout. CLI and MCP remain developer and compatibility surfaces. The root `package.json` is the single version source. Runtime artifacts, benchmark output, installer staging, and local configuration are not part of the npm package or Git source release.
