# OpenCode++ v0.2.1

This patch release fixes OpenCode Desktop plugin discovery and corrects the control-surface boundary.

## Highlights

- Fixes global plugin loading on OpenCode 1.18.18 by exposing a loader-compatible CommonJS function.
- Removes the legacy control Slash Commands because OpenCode Markdown commands are model prompt templates.
- Keeps `opencode_plusplus_status`, `opencode_plusplus_enable`, and `opencode_plusplus_disable` as model-visible Desktop tools.
- Provides direct, model-free local controls through `--status`, `--enable`, and `--disable` on the Windows installer.
- Preserves the enabled state during upgrades and refreshes plugin version metadata.
- Replaces the Node SEA installer with a compact .NET Framework bootstrap, reducing the EXE from 96.6 MiB to about 3.5 MiB.

## Install

1. Fully exit OpenCode Desktop.
2. Download `opencode-plusplus-setup-win-x64.exe`.
3. Verify the accompanying SHA256 file.
4. Run the installer and restart OpenCode Desktop.

The installer is per-user, requires no administrator privileges, and is not commercially code-signed.
