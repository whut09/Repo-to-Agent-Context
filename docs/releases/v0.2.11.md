# OpenCode++ v0.2.11

This release makes the Desktop result explicitly show what OpenCode++ itself did.

## What Changed

- Every Harness result now includes `actionSummary` with recorded `observed`, `prevented`, `requested`, `repaired`, `verified`, and `unresolved` items.
- `humanReadable` starts with the same bilingual action summary, current working-tree hash, and evidence gaps.
- Desktop app logs include counts for prevented, repaired, verified, and unresolved interventions.
- The primary mode now tells the current model to copy the recorded summary instead of replacing it with commit lists or external test claims.
- `human-review` now means the exact missing evidence or boundary decision is reported; it is not a request to repeat the whole task.

The summary is an audit of plugin-recorded facts. It does not expose hidden model reasoning and does not treat model or user claims as OpenCode++ evidence.

## Install

Close OpenCode Desktop, run `opencode-plusplus-setup-win-x64.exe`, restart OpenCode Desktop, and select **OpenCode++**. After `evaluate` or `next`, read the `OpenCode++ action summary` at the top of the result, or call `opencode_plusplus_dashboard`.
