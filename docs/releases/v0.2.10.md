# OpenCode++ v0.2.10

This release prevents Desktop Harness wait loops and repeated verification caused by runtime artifacts.

## Fixed

- Desktop guidance now uses in-process OpenCode++ tools and forbids CLI, `Start-Sleep`, `sleep`, and polling loops.
- The sidecar blocks artificial wait commands with a concrete next step.
- Plugin Context is cached by the current working-tree fingerprint and concurrent builds are coalesced.
- `.agent-context` and generated `AGENTS.md` watcher events no longer mark the repository dirty or trigger another verification cycle.
- The Desktop runtime continues to return structured `human-review` when no real test command is configured.

## Install

Close OpenCode Desktop, run `opencode-plusplus-setup-win-x64.exe`, restart OpenCode Desktop, and select **OpenCode++**.
